03 — AUTONOMOUS STACK BUILDER V3

Tell the workspace what you want to build.

The builder now uses an LLM to reason about your goal and the actual agents and tools currently available in the directory.

The builder only selects components from the current directory. If the available ecosystem cannot satisfy an important capability, it reports that capability as a gap instead of inventing a solution.
